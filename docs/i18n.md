# 中英文国际化

界面文案维护在 `lib/l10n/app_en.arb` 和 `lib/l10n/app_zh.arb`，通过 `flutter gen-l10n` 生成 Dart 代码。不要手动编辑 `app_localizations*.dart`。

- 按钮、提示、错误、状态和空列表文案使用 `AppLocalizations.of(context)`；不要在组件内判断语言后拼接文案。
- 带数量的完整短语使用 ICU 参数和复数规则，例如 `characterCount(count)`，避免英文出现 `2 Character`。
- 日期和时间使用 `Localizations.localeOf(context)` 传给 `DateFormat`。
- 接口中的 `I18nText` 展示时使用 `I18nHelper.getDisplayNameFromI18n`，当前语言内容缺失时回退到另一种语言。
- 编辑时使用 `getEditableNameFromI18n`，只读写当前语言自身的值。角色、果实和团体详情页会分别保留中英文名称草稿，避免切换语言后误写另一种语言。
- 品牌名、备案编号、语言选择器的自称和缩写、用户输入、日志、路由及接口枚举值不作为界面翻译处理。

常用词汇：Health / 血量、Energy / 精力、Battle Rating / 战斗分、Teamwork Bonus / 团体增益、Awakened / 已觉醒。登录身份使用 Role，作品中的角色使用 Character。

验证：

```sh
flutter gen-l10n
flutter analyze --no-pub
flutter test --no-pub test/i18n_test.dart
flutter test --no-pub --platform chrome test/i18n_editor_test.dart test/resource_detail_test.dart test/resource_layout_test.dart test/resource_density_test.dart
```

页面间接依赖浏览器专用 API，页面测试需使用 Chrome；基础国际化测试可直接在 Dart VM 运行。
